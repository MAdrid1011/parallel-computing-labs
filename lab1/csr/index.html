    稀疏矩阵与 CSR¶

    先把 OpenMP 放在一边。我们从“怎样保存稀疏矩阵”和“怎样完成一次乘法”开始。

    1. 为什么不存所有的零？¶

    按普通二维数组保存 M×K 的矩阵，需要为每个元素分配空间。如果其中绝大部分是零，这些空间和遍历工作就很浪费。

    本实验使用 CSR（Compressed Sparse Row，压缩稀疏行）。它按行保存非零元素，并用三个数组描述位置：

    数组 保存什么？
    values 所有非零元素的值。
    col_idx 每个非零元素位于原矩阵的哪一列。
    row_ptr 每一行在前两个数组中的起始位置；最后一项为总非零数。

    2. 跟着一个存储示例读 CSR¶

    下面的矩阵只用于说明存储格式：

    A = [ 2  0  0  5
      0  3  0  0
      4  0  7  0 ]

values  = [2, 5, 3, 4, 7]
col_idx = [0, 3, 1, 0, 2]
row_ptr = [0, 2, 3, 5]

    第 0 行使用下标区间 [row_ptr[0], row_ptr[1])，也就是 [0,2)：有两个非零元素，值分别为 2 和 5，列号分别为 0 和 3。

    第 1 行使用 [2,3)，只有一个非零元素。第 2 行使用 [3,5)。因此第 i 行的非零数可以直接计算为：

    row_ptr[i + 1] - row_ptr[i]

    这里的区间都是左闭右开：包含起始下标，不包含结束下标。这与 C++ 中 p < end 的循环写法对应。

    空行怎样表示？

    如果相邻两项 row_ptr[i] 和 row_ptr[i+1] 相同，说明这一行没有非零元素。对应输出行没有来自 A 的非零贡献。

    3. 一个非零元素会用到 B 的哪一部分？¶

    对于一个非零元素 A[i,k]，计算需要访问 B 的第 k 行，并把结果累加到 C 的第 i 行：

    C[i,:] += A[i,k] × B[k,:]

    例如，存储示例的第 0 行最终计算：

    C[0,:] = 2 × B[0,:] + 5 × B[3,:]

    列号 k 从 col_idx 取得，非零值从 values 取得；不需要再遍历 A 的所有 K 列。

    4. 对应的基本循环¶

    下面用简化写法表示 CSR 乘法，省略类型和计时部分。输出 C 在计算前清零。

    for (size_t i = 0; i < M; ++i) {
    for (size_t p = row_ptr[i]; p < row_ptr[i + 1]; ++p) {
        const size_t k = col_idx[p];
        const double a = values[p];
        for (size_t j = 0; j < N; ++j) {
            C[i * N + j] += a * B[k * N + j];
        }
    }
}

    最内层 j 连续增加，所以 B 的一行和 C 的一行都按连续地址访问。每个非零元素参与 N 次乘加，总乘加次数为 nnz × N。

    先确认三个下标的含义

    i 是 A、C 的行号；p 是 CSR 非零数组中的位置；k 是这个非零元素在 A 中的列号，也是 B 的行号。p 和 k 不是同一种下标。

    5. 在实际源码中找到它们¶

    打开解压或克隆得到的 Lab1：

    1. include/matrix.hpp：查看 CSR 和稠密矩阵的数据结构。
    2. src/matrix.cpp：查看三个输入分布如何生成非零位置。
    3. src/spmm_serial.cpp：从串行入口开始阅读。
    4. include/detail/row_kernel.hpp：查看实际的逐行乘加和 SIMD 列循环。

    先挑一行，根据 row_ptr 说出它会访问哪些非零元素，再根据 col_idx 说出它会读取 B 的哪些行。完成这个过程后，就能继续讨论“这行交给哪个线程”。
