<div class="lab-wordmark">PARALLEL LAB</div>

## 实验简介

中国科学院大学《并行处理》研究生课程实验围绕并行编程、程序优化和并行架构展开。

我们已经熟悉让程序按顺序完成一项工作。如果把这项工作交给多个线程、多个进程，甚至一组专门的计算电路，会发生什么？程序怎样分工，数据怎样共享，又为什么有时增加计算资源却没有变快？这些问题都可以通过动手实验来认识。

这套实验从熟悉的矩阵和计数程序出发，逐步介绍 OpenMP、MPI，以及 SPM 与脉动阵列的硬件仿真。每个实验都提供完整实现。大家可以先读懂一个基本版本，再运行不同实现，改变参数，观察自己的电脑上发生了什么。

## 实验路线

建议按 Lab1 → Lab5 的顺序阅读。前面建立的“任务、数据、等待”三个视角，在后面的实验中还会出现。

| 实验 | 我们要完成什么？ | 从这里开始 |
|---|---|---|
| **Lab1 · OpenMP 稀疏矩阵乘法** | 只处理矩阵中的非零元素，把乘法分给多个线程；认识任务划分、负载均衡和分块。 | [实验介绍](lab1/index.md) |
| **Lab2 · OpenMP 矩阵转置** | 改变矩阵元素的访问顺序；认识缓存与局部性。 | [实验介绍](lab2/index.md) |
| **Lab3 · OpenMP 直方图** | 让多个线程共同计数；认识锁、原子操作和线程私有数据。 | [实验介绍](lab3/index.md) |
| **Lab4 · MPI 稀疏矩阵乘法** | 让各进程保存自己的数据，通过消息获得所需矩阵行；认识通信与计算的关系。 | [实验介绍](lab4/index.md) |
| **Lab5 · SPM 与脉动阵列仿真** | 让数据经过片上存储和计算阵列，完成稠密矩阵乘法；认识数据复用、双缓冲和硬件周期。 | [实验介绍](lab5/index.md) |

??? info "OpenMP、MPI 和 Verilator 分别是什么？"
    **OpenMP** 帮助我们在同一个进程里使用多个线程。这些线程能够访问同一份内存，适合先学习如何拆分循环、怎样协调共享数据。

    **MPI** 提供进程之间的消息传递接口。每个进程有自己的数据，通过显式通信交换信息。同一台电脑就能启动多个 MPI 进程，多台电脑也可以参与同一次计算。

    **Verilator** 把硬件描述转换成可执行的仿真模型。我们用它观察设计中的时钟、数据传输和计算过程，不需要准备 FPGA 开发板。

## 如何使用本文档？

### 关于阅读顺序

每个实验的文档分为四个部分：

1. **实验介绍**：说明要解决的问题，以及本次要认识的概念。
2. **实验教程**：从直观例子讲到实际实现，告诉大家应该从哪些文件开始阅读。
3. **操作步骤**：列出依赖安装、构建命令、运行参数和输出字段。再次运行时，可以直接查这一页。
4. **核心代码讲解**：用一个小例子贯穿实际代码，沿着输入、分工、计算与结果组合的顺序，解释各个实现和参数之间的关系。

完成快速验证后，可以对照“核心代码讲解”理解已运行的程序，再沿着教程中的“动手试一试”改变参数、比较现象。请把测量得到的耗时、周期和数据量保留下来，再结合实现解释现象。
