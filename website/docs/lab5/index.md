# Lab5：SPM 与脉动阵列仿真

最后一个实验把视角从 CPU 程序转到计算电路。我们用 Verilator 运行一个带 SPM 和脉动阵列的设计，计算稠密矩阵乘法。

## 1. 实验背景

Lab1 和 Lab4 利用 A 的稀疏性，只处理非零元素。本实验的 A、B 都是稠密矩阵，矩阵元素按分块送入计算阵列。

阵列里有多行、多列处理单元（PE）。每个 PE 完成乘加，并把收到的 A、B 元素继续传给相邻 PE。数据在阵列中逐拍流动，同一元素可以参与多个输出的计算。

阵列需要不断获得数据。软件 DRAM 保存完整矩阵，DMA 搬运分块，SPM 保存阵列当前使用的数据。我们会改变阵列边长、分块尺寸和缓冲方式，观察完整计算过程。

## 2. 实验目标

1. 根据数据流说明软件 DRAM、DMA、SPM 和阵列各自的作用。
2. 理解 A 向右、B 向下传递，以及 PE 保留输出部分和的方式。
3. 区分矩阵尺寸、分块尺寸和物理阵列尺寸。
4. 理解单缓冲与双缓冲怎样安排加载和计算。
5. 用周期、传输字节数和有效乘加次数观察设计。

## 3. 实验内容

```text
软件 DRAM → 读 DMA → A/B 的 SPM → 脉动阵列
                                    ↓
软件 DRAM ← 写 DMA ← C 的 SPM ← 输出部分和
```

默认运行三组矩阵规模、三种阵列边长、三种分块尺寸，以及单缓冲、双缓冲两种方式。A、B 使用 `int16` 元素，C 和部分和使用 `int32`。

!!! note "哪些工作在哪里执行？"
    C++ 程序生成矩阵、保存软件内存并驱动仿真时钟。矩阵乘加由 RTL 中的 PE 执行。软件 DRAM 提供延迟和逐拍握手行为，便于观察供数与计算的关系。
