# Lab2：OpenMP 矩阵转置

在 Lab1 中，我们关注把计算分给谁。这个实验把重点放到另一个问题：**同样的数据，按什么顺序访问？**

## 1. 实验背景

矩阵转置交换元素的行列位置：

```text
B[j,i] = A[i,j]
```

实验中的 A、B 都按行连续存储。如果按 A 的一行一行读取，读地址是连续的，但写到 B 时会跨越多行。

转置几乎不需要算术运算，但仍可能花费很多时间。数据从内存进入缓存、缓存行是否被充分使用，以及同一缓存行多久会再次访问，都与时间有关。

## 2. 实验目标

1. 根据行优先布局写出一个元素的内存下标。
2. 说明按行转置为什么产生跨行写入。
3. 理解二维分块怎样缩短数据再次被访问的间隔。
4. 在相同矩阵和线程数下比较分块尺寸。
5. 区分局部性与负载均衡两个观察方向。

## 3. 实验内容

| 实现 | 访问方式 |
|---|---|
| Serial | 串行执行普通的按行转置。 |
| Naive | 把输入行静态分配给 OpenMP 线程。 |
| Tiled | 将矩阵划分为二维 tile，按块分配给线程。 |

默认运行五组矩阵规模和四种分块边长。在这个任务中，每个输入元素都对应一次输出写入，完整行的工作量相同；我们主要观察数据访问方式。
