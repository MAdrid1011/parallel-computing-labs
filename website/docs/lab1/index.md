# Lab1：OpenMP 稀疏矩阵乘法

这是我们使用 OpenMP 的第一个实验。我们会把一个矩阵乘法交给多个线程，并尝试不同的分工方式。

## 1. 实验背景

矩阵乘法可以写成：

```text
A: M × K
B: K × N
C: M × N
C[i,j] = Σ A[i,k] × B[k,j]
```

本实验的 A 是**稀疏矩阵**：大部分元素为零。B 和 C 是按行存储的稠密矩阵。零乘任何数仍然是零，因此我们只需要处理 A 的非零元素。这类“稀疏矩阵 × 稠密矩阵”的乘法称为 **SpMM**。

接下来还有一个问题：不同的行可能包含不同数量的非零元素。如果只是平均分配行数，某个线程可能承担了大部分计算，其余线程很早就完成了。

!!! note "本实验的两个观察方向"
    **任务划分**：线程分别拿到了多少实际计算？

    **数据访问**：一次计算处理哪些输出列，怎样复用矩阵元素和部分和？

## 2. 实验目标

完成本实验后，希望大家能够：

1. 根据 CSR 的三个数组找到某一行的非零元素。
2. 说明一个非零元素如何参与一整行输出的计算。
3. 理解按行静态分配、动态分配与按非零数分块的区别。
4. 找到分块实现中任务分配、列循环和局部部分和的位置。
5. 在相同输入下比较实现，并区分算法改进和线程扩展。

## 3. 实验内容

| 实现 | 代码里改变了什么？ |
|---|---|
| Serial | 按 CSR 行顺序完成计算。 |
| Rows | 按行分配给线程，使用静态调度。 |
| Dynamic | 每次领取一行，完成后继续领取，使用动态调度。 |
| NNZ blocks | 先根据非零数划分连续行块，再分配给线程。 |
| Tiled | 将行块和输出列块组合为任务，使用局部部分和与 SIMD 列循环。 |

我们会运行 `uniform`、`skewed` 和 `blocked` 三种稀疏分布。固定矩阵参数时，它们的总非零数一致，但非零元素的位置和各行的工作量不同。
